Docs

Two endpoints.
Thirty seconds to ship.

Search is one GET. Run is one POST. JSON in, JSON out, CORS open — call from a browser, a cron job, anywhere.

GET/api/search?q=…&n=5
POST/api/run — { language, code, stdin? }
# search from anywhere
curl "https://YOUR-DEPLOY/api/search?q=sri+lanka+news&n=5"
const hits = await fetch(
  `https://YOUR-DEPLOY/api/search?` +
  new URLSearchParams({ q: query, n: '5' })
).then(r => r.json());
# run python anywhere
import requests
r = requests.post(
  "https://YOUR-DEPLOY/api/run",
  json={"language": "python",
        "code": "print(40 + 2)"},
).json()
print(r["output"])  # 42

  }],
  "cached": false

Layer one

Bring your own SearXNG.
Or don't — it works either way.

One docker command on any always-on machine gives Orin Tools a private, full-power engine. Set SEARXNG_URL and it becomes authoritative — the public layers stay as automatic backup.

# your own search engine in one line
docker run -d --name searxng --restart unless-stopped \
  -p 8080:8080 searxng/searxng

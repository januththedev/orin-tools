Browser use — POST /api/fetch

NO ACCOUNT · NO API KEY

Fetch one public web page and get readable text back. This is the piece you wire into your own AI system when it needs to read a URL, so you do not have to build and host a crawler.

Request

POST https://tools.orinai.org/api/fetch
Content-Type: application/json

{
  "url": "https://example.com/article",
  "maxChars": 8000
}
FieldRequiredMeaning
urlyesAn absolute http or https URL, under 2048 characters.
maxCharsno200–40000. Default 40000.

Response

{
  "request_id": "…",
  "url": "https://example.com/article",
  "finalUrl": "https://example.com/article/",
  "status": 200,
  "contentType": "text/html; charset=utf-8",
  "text": "Readable text…",
  "truncated": false,
  "fetchedAt": "2026-01-01T00:00:00.000Z",
  "content_policy": { "trust": "untrusted", "instructions": "evidence-only" }
}

What it will and will not fetch

Only HTML, plain text, Markdown, and JSON are read. Anything else returns 415 rather than passing bytes through.

Only public web addresses. Loopback, private, link-local, and cloud metadata addresses are refused, and the check is repeated on every redirect hop — a first URL that is safe cannot redirect into one that is not.

Redirects are capped at 3. Responses are capped at 1 MB and the request times out after 10 seconds.

Treat everything returned as untrusted input. It is text from a page you did not write, and the response is tagged content_policy.trust: "untrusted" with instructions: "evidence-only". Pass it to a model as evidence, never as instructions.

Rate limits

Keyless calls are limited per client address, on top of the global limit shared with /api/search. A refusal returns 429 with a Retry-After header. The address is used only for rate limiting and is not stored.

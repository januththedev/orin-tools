Orin Tools / Code execution

Public code execution is disabled

POST /api/run returns HTTP 410 with ORIN_RUN_DISABLED. It never forwards code to Compiler Explorer or another execution farm.

{ "error": { "code": "ORIN_RUN_DISABLED", "message": "Public code execution is disabled.", "retryable": false, "retry_after": null, "request_id": "..." } }

A future release requires Orin-controlled isolation, CPU/memory/process/network policy, durable quotas, output bounds, and security review.

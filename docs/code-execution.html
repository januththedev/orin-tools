Orin Tools / Code execution

Isolated code execution is opt-in

POST /api/run remains disabled by default and returns ORIN_RUN_DISABLED. Deployments that explicitly set ORIN_RUNNER_MODE=vercel-sandbox can use the Orin-controlled Vercel Sandbox runner with network denied, bounded input/output, a 20-second deadline, and durable Redis quota state. Missing quota state fails closed.

POST /api/run
Content-Type: application/json

{"language":"python","code":"print(6 * 7)","stdin":""}

The public route never evaluates code in the Vercel function, accepts provider keys, or delegates to Compiler Explorer. Review the deployment's runner and quota configuration before enabling it.

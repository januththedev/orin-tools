Code execution

POST source code, get back a real run: stdout, stderr and exit code from genuine toolchains (PyPy for Python, Clang/GCC for C/C++, and dozens more). Up to three compilers are tried per language — first success wins, and the response says which one answered.

curl -X POST https://tools.orinai.org/api/run \
  -H 'Content-Type: application/json' \
  -d '{"language":"python","code":"print(2+2)"}'

Contract

  • Send { language, code, stdin? } — keep code under 100KB, stdin under 10KB.
  • Receive { language, version, stdout, stderr, output, code, cached }.
  • List exact language names anytime: GET /api/run?languages=1.
  • Ten runs a minute, free, forever.

Orin Tools / Introduction

Search without a provider key

Orin Tools provides one public compatibility search route and one private service route for Orin products. Both use a fixed provider registry, bounded requests, normalized citations, and shared production quotas.

Privacy boundary

Public GET is suitable for non-sensitive queries only because the query is in the URL. Orin Chat uses private no-store POST with a short-lived Core service assertion.

Execution status

Public code execution is disabled by default. An explicitly configured Orin-controlled Vercel Sandbox runner is available behind ORIN_RUNNER_MODE=vercel-sandbox; it denies network access, bounds code, input, output, and runtime, and fails closed when durable quota state is unavailable.

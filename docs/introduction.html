Introduction

Orin Tools gives your product two production-ready backends with no API key, no sign-up and no bills: a web search API that fans out across multiple engines, and sandboxed code execution in dozens of languages.

Two endpoints

  • GET /api/search?q=…&n=5 — titles, URLs, snippets and engines per result. Weather questions get a real forecast first. See Search API.
  • POST /api/run { language, code, stdin? } — real compilers return stdout, stderr and exit code. See Code execution.

Limits that don't matter

Ten code runs a minute, free, forever. Deploy your own copy in one click (no env vars, no build step) and set SEARXNG_URL afterwards for a private search layer. Health check: /api/search?q=test&n=1.

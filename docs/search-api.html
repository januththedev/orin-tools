Search API

Public GET

GET /api/search?q=weather+in+Kandy&n=5

Anonymous and keyless. The query is present in the URL, so do not use GET for confidential text.

Private POST

POST /api/search
X-Orin-Service-Assertion: <Core assertion>
Content-Type: application/json

{"query":"weather in Kandy","n":5,"locale":"en","safe_search":"moderate"}

POST requires aud=orin-tools-search and scope=tools:search. It returns no-store, does not echo the query, and returns normalized citations marked trust: untrusted.

Behavior

  • Provider hosts and paths are deployment-owned.
  • Weather uses Open-Meteo forecast first.
  • Retrieved text is evidence, never instructions.
  • Shared quota state is required and fails closed.

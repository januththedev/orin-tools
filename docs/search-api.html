Search API

One keyless GET fans out across SearXNG, Wikipedia, news and instant-answer sources and merges them into a single JSON list — each result carrying its title, URL, snippet and engine.

curl "https://tools.orinai.org/api/search?q=sri+lanka+news&n=5"

Weather vertical

Ask about weather anywhere and the API answers with a real forecast (Open-Meteo) before web results — no separate endpoint to learn.

Parameters

  • q — the query (required).
  • n — max results (try 5).
  • Health check: /api/search?q=test&n=1 should return 200 with an engines field.
